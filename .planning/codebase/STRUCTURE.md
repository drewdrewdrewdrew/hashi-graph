│   └── hashi_puzzle_solver/

│   └── hashi_puzzle_solver/
│       ├── losses/           # Loss modules
│       ├── models/           # GNN components
│       ├── trainers/         # Training strategies
│       └── utils/            # Helper utilities

## Directory Purposes

**`configs/`:**
- Purpose: Named YAML configuration files, one per training scenario
- Contains: `base_config.yaml`, `transformer_solver.yaml`, `gat_solver.yaml`, `gine_solver.yaml`, `ar_solver.yaml`, `diffusion_solver.yaml`, `diffusion_solver_continuous.yaml`, `diffusion_solver_discrete.yaml`, `diffusion_solver_flow_blind.yaml`, `diffusion_solver_hierarchical.yaml`, `masking_experiment.yaml`, `tune_config.yaml`
- Key files: `configs/base_config.yaml` (default training config), `configs/tune_config.yaml` (Optuna search space)

**`dataset/`:**
- Purpose: Puzzle data storage at two stages
- Contains: `raw/puzzle_NNNNN.json` (one file per puzzle, contains graph + params + split label); `processed_*/` (PyG tensor cache, auto-generated by `HashiDataset`)
- Key files: Do not edit `processed_*/` — delete to force re-processing

**`generator/`:**
- Purpose: C-based puzzle generator ported from Simon Tatham's Puzzles collection
- Contains: `bridges.c`, `bridges_gen.c`, `bridges_gen` (compiled binary), `dsf.c`, `findloop.c`, `malloc.c`, `misc.c`, `nullfe.c`, `random.c`, `puzzles.h`, `Makefile`
- Key files: `generator/bridges_gen` (the executable called by `bridges_gen.py`)

**`models/`:**
- Purpose: Saved training runs (checkpoints + config)
- Contains: Per-run directories named `model_YYYYMMDD_HHMMSS/` each with `model_latest.pt`, `model_best.pt`, `model.pt` (config)
- Generated: Yes. Committed: No (gitignored)

**`scripts/`:**
- Purpose: Standalone post-training analysis and diagnostic tools
- Contains: `evaluate_model.py`, `find_and_render_puzzles.py`, `mlflow_forensic_analysis.py`, `profile_puzzles.py`, `sweep_merge_margin.py`, `tune_rollout.py`
- Key files: `scripts/evaluate_model.py` (run inference and diagnostics on a saved model)

**`src/hashi_puzzle_solver/`:**
- Purpose: Legacy implementation — kept for reference and legacy test compatibility only
- Contains: Flat module layout (all files at one level), `models/` subdirectory with individual GNN files
- Key files: `src/hashi_puzzle_solver/engine.py`, `src/hashi_puzzle_solver/train.py`
- Note: `pyproject.toml` sets `pythonpath = ["src"]` and `testpaths = ["tests"]` — legacy tests still run against `src/`

**`src2/hashi_puzzle_solver/`:**
- Purpose: Canonical refactored implementation; all new development targets this package
- Key files: `train.py` (entry point), `engine.py` (Trainer facade), `data.py` (HashiDataset), `masking.py` (MaskingStrategy), `callbacks.py`, `bridges_gen.py`, `create_data.py`, `tune.py`, `tune_space.py`

**`src2/hashi_puzzle_solver/models/`:**
- Purpose: GNN component library
- Contains: `config.py` (typed dataclasses), `factory.py` (ModelFactory), `core.py` (HashiGraphModel), `backbone.py` (GraphBackbone), `encoders.py` (NodeEncoder, EdgeEncoder), `heads.py` (EdgeHead, ProphetHead), `features.py` (NodeFeatureManager, EdgeFeatureManager), `common.py` (build_mlp helper), `node_encoder.py`, `gat.py`, `gcn.py`, `gine.py`, `transformer.py`

**`src2/hashi_puzzle_solver/trainers/`:**
- Purpose: Training strategy implementations
- Contains: `base.py` (BaseTrainer, EarlyStopper, EpochMetrics), `one_shot.py` (OneShotTrainer), `ar.py` (ARTrainer, ARState), `diffusion.py` (DiffusionTrainer)

**`src2/hashi_puzzle_solver/losses/`:**
- Purpose: Modular loss components
- Contains: `base.py` (LossModule ABC), `calculator.py` (HashiLossCalculator), `degree.py` (DegreeLoss), `crossing.py` (CrossingLoss), `verification.py` (VerificationLoss), `legacy.py` (compute_combined_loss — used by DiffusionTrainer)

**`src2/hashi_puzzle_solver/utils/`:**
- Purpose: Shared helper functions
- Contains: `common.py` (get_device, load_config, custom_collate_with_conflicts, flatten_config), `train_utils.py` (calculate_batch_perfect_puzzles, get_edge_batch_indices, update_node_features, save_config_to_model_dir), `ar_utils.py`, `diffusion_utils.py`, `evaluation_utils.py`, `graph_utils.py` (generate_puzzle_graph), `bridges_utils.py` (convert_to_hashi_format)

**`tests_src2/`:**
- Purpose: Tests for the canonical `src2/` package
- Contains: `conftest.py`, `test_ar_logic.py`, `test_components.py`, `test_config.py`, `test_config_schema.py`, `test_data.py`, `test_dataloader_sampling.py`, `test_diffusion.py`, `test_encoders.py`, `test_features.py`, `test_losses.py`, `test_model_shell.py`, `test_noise_projection.py`, `test_parity.py`, `test_training_start.py`

**`tests/`:**
- Purpose: Legacy tests for `src/` package
- Contains: Tests covering the original flat implementation

## Key File Locations

**Entry Points:**
- `src2/hashi_puzzle_solver/train.py`: Training entry point (`main()`)
- `src2/hashi_puzzle_solver/tune.py`: Optuna hyperparameter tuning entry point
- `src2/hashi_puzzle_solver/create_data.py`: Dataset generation entry point

**Configuration:**
- `configs/base_config.yaml`: Default config (one-shot transformer)
- `src2/hashi_puzzle_solver/models/config.py`: Typed config dataclasses (`HashiModelConfig`)
- `pyproject.toml`: Project dependencies, ruff rules, pytest paths

**Core Logic:**
- `src2/hashi_puzzle_solver/engine.py`: `Trainer` facade + `create_trainer()` dispatch factory
- `src2/hashi_puzzle_solver/trainers/base.py`: `BaseTrainer` with full training loop
- `src2/hashi_puzzle_solver/models/core.py`: `HashiGraphModel` forward pass
- `src2/hashi_puzzle_solver/models/factory.py`: `ModelFactory.create_model()`
- `src2/hashi_puzzle_solver/data.py`: `HashiDataset`, `FeatureSchema`
- `src2/hashi_puzzle_solver/losses/calculator.py`: `HashiLossCalculator`

**Testing:**
- `tests_src2/conftest.py`: Shared fixtures for canonical tests
- `tests_src2/`: All tests for `src2/` code

## Naming Conventions

**Files:**
- Snake case for all Python modules: `train_utils.py`, `bridges_gen.py`, `one_shot.py`
- Config files named by mode/variant: `ar_solver.yaml`, `diffusion_solver_continuous.yaml`
- Model checkpoints: `model_YYYYMMDD_HHMMSS/` directories; `model_latest.pt`, `model_best.pt`
- Dataset puzzles: `puzzle_NNNNN.json` (zero-padded 5-digit ID)

**Directories:**
- Package modules use snake case: `hashi_puzzle_solver/`, `trainers/`, `losses/`
- Grouping dirs reflect layer/concern: `models/`, `trainers/`, `losses/`, `utils/`

**Classes:**
- PascalCase: `HashiGraphModel`, `BaseTrainer`, `OneShotTrainer`, `HashiLossCalculator`, `EpochMetrics`
- Config dataclasses suffixed with `Config`: `HashiModelConfig`, `DataConfig`, `TrainingConfig`
- Callbacks suffixed with `Callback`: `CheckpointCallback`, `MLflowCallback`

**Functions:**
- Snake case: `create_trainer()`, `generate_puzzle_graph()`, `get_edge_batch_indices()`

## Where to Add New Code

**New Training Mode:**
- Subclass `BaseTrainer` in `src2/hashi_puzzle_solver/trainers/<mode_name>.py`
- Override `run_epoch()` at minimum; add `run_rollout()` if applicable
- Register in `src2/hashi_puzzle_solver/engine.py:create_trainer()`
- Add YAML config to `configs/<mode_name>_solver.yaml`

**New Loss Component:**
- Subclass `LossModule` in `src2/hashi_puzzle_solver/losses/<name>.py`
- Register in `src2/hashi_puzzle_solver/losses/calculator.py` and `losses/__init__.py`
- Add weight field to `LossWeightsConfig` in `models/config.py`

**New Node or Edge Feature:**
- Add toggle boolean to `ModelConfig` in `src2/hashi_puzzle_solver/models/config.py`
- Update `NodeFeatureManager` or `EdgeFeatureManager` in `src2/hashi_puzzle_solver/models/features.py`
- Update `HashiDataset` in `src2/hashi_puzzle_solver/data.py` to populate the feature
- Pass toggle through `BaseTrainer.create_dataloader()` to `HashiDataset`

**New Utility:**
- Shared helpers: `src2/hashi_puzzle_solver/utils/common.py`
- Training-specific helpers: `src2/hashi_puzzle_solver/utils/train_utils.py`
- Mode-specific helpers: `src2/hashi_puzzle_solver/utils/ar_utils.py` or `diffusion_utils.py`

**New Tests:**
- Place in `tests_src2/test_<module_name>.py`
- Use fixtures from `tests_src2/conftest.py`

**New Config Variant:**
- Copy closest existing YAML from `configs/` and modify
- All keys must correspond to fields in the relevant `*Config` dataclass (unknown keys will cause `TypeError` at `from_dict()`)

## Special Directories

**`dataset/processed_*/`:**
- Purpose: Auto-generated PyG tensor cache created by `HashiDataset` on first run
- Generated: Yes (by `torch_geometric.data.Dataset`)
- Committed: No (gitignored)
- Note: Directory name includes a hash of dataset parameters; delete to force re-processing

**`models/`:**
- Purpose: Output directory for training run checkpoints
- Generated: Yes (by `train.py`)
- Committed: No (gitignored at repo root via `.gitignore`)

**`.mlop/`:**
- Purpose: mlop run tracking configuration
- Location: `.mlop/hashi-graph/train-gnn/`
- Committed: Yes

**`generator/bridges_gen` (binary):**
- Purpose: Pre-compiled C binary for puzzle generation
- Generated: Via `generator/Makefile`
- Committed: Yes (binary checked in)
